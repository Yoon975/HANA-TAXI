택시 사업 자동화 — 사용방법
================================

1. 실행하기
-----------
1) 이 폴더의 TaxiApp.exe 를 더블클릭합니다.
2) 잠시 기다리면 인터넷 브라우저(Chrome 등)가 열리고 화면이 나옵니다.
3) 화면이 안 열리면 주소창에 직접 입력해 보세요.
   http://127.0.0.1:8501

※ 인터넷이 필요합니다. (AI 요약·수정 기능)
※ 회사 PC에서 “애플리케이션 제어 정책” 등으로 막히면 IT 담당자에게 허용을 요청하세요.


2. 종료하기
-----------
- 작업표시줄 오른쪽(트레이)의 택시 앱 아이콘을 오른쪽 클릭 → 종료
- 또는 브라우저 탭을 닫은 뒤, 트레이에서 종료


3. 파일이 저장되는 곳
---------------------
모든 자료는 이 PC의 「문서」 폴더 아래에 자동으로 모입니다.

  문서\택시자동화\
    ├─ pdf_공문\          ← 업로드한 PDF 공문
    ├─ excel_장부\
    │    ├─ 원본\
    │    ├─ 수정본\
    │    ├─ 템플릿\
    │    └─ 백업\         ← AI 적용 전 자동 백업
    ├─ analysis_리포트\   ← 분석 결과
    └─ _config\           ← API 키, 차량·기사 마스터(vehicles.json, drivers.json)


4. 화면 구성 (위쪽 탭)
----------------------
① AI 채팅
  - 차량·기사 등록 / 수정 / 삭제 (말로 요청)
  - 변경은 「미리보기」 확인 후 「적용」해야 저장됩니다
  - 일반 업무 질문(배차·공문·장부)도 가능

② 공문 모아보기
  - PDF 공문 업로드 · 저장 · 목록 보기
  - 텍스트 미리보기
  - (API 키 있으면) AI 요약

③ 엑셀 장부
  - 장부(.xlsx) 업로드 또는 표준 템플릿 만들기
  - 시트 선택 · 내용 확인
  - 열 매핑 저장 (날짜/금액 등 어떤 열인지 지정)

④ AI 자동 수정
  - 말로 명령 → 「계획 미리보기」 → 확인 후 「적용」
  - 적용할 때만 새 파일로 저장되고, 백업이 남습니다
  - 잘못되면 「백업으로 되돌리기」

⑤ 분석
  - 장부 기준으로 간단한 분석·리포트


5. AI(Gemini) 키 설정 — 요약·자동수정용
----------------------------------------
키가 없어도 공문 저장·엑셀·분석은 됩니다.
요약·AI 수정만 키가 필요합니다.

1) 브라우저로 키 발급
   https://aistudio.google.com/apikey
   Google 계정 로그인 → Create API key

2) 앱 왼쪽 사이드바
   - Gemini API 키 붙여넣기 → 「키 저장」
   - 모델은 보통 gemini-3.5-flash 권장
   - 「연결 테스트」로 확인

※ 선불(prepaid) 크레딧이 0인 프로젝트 키는 오류가 납니다.
  → AI Studio에서 무료(선불 없는) 프로젝트로 새 키를 발급하세요.
※ 키는 문서\택시자동화\_config 에만 저장됩니다. 다른 사람에게 알려 주지 마세요.


6. 자주 하는 작업 순서 (예시)
------------------------------
[차량·기사 등록]
  AI 채팅 → 「차량 12가3456 등록」 / 「김철수 기사 추가」
  → 미리보기 확인 → 적용

[차량·기사 수정·삭제]
  AI 채팅 → 「12가3456 삭제」 / 「김철수 이름을 김철수로 수정」
  → 미리보기 → 적용

[공문만 보관]
  공문 탭 → PDF 업로드 → 저장

[공문 요약]
  사이드바에 키 저장 → 공문 선택 → AI 요약

[장부 준비]
  엑셀 탭 → 업로드 또는 템플릿 만들기 → 시트 선택 → 열 매핑 저장

[AI로 장부 수정]
  AI 탭 → 명령 입력 → 계획 미리보기 → 내용 확인 → 적용


7. 문제 해결
------------
● 화면이 안 열림
  - exe를 다시 실행
  - http://127.0.0.1:8501 직접 접속
  - 다른 TaxiApp이 이미 켜져 있으면 트레이에서 종료 후 다시 실행

● AI 오류 (429 / 크레딧 소진)
  - 무료 프로젝트로 새 API 키 발급 후 사이드바에 다시 저장

● AI 오류 (모델 없음 / 404)
  - 사이드바에서 다른 모델(gemini-3.5-flash 등) 선택

● 키가 틀렸다는 메시지
  - 키를 다시 복사해 「키 저장」 → 연결 테스트

● 엑셀/프로그램이 정책으로 차단됨
  - 회사 PC 보안 정책일 수 있습니다. IT 담당자에게 TaxiApp·관련 DLL 허용 요청


8. 주의사항
-----------
- Python을 따로 설치할 필요는 없습니다. (이 폴더의 exe로 실행)
- 이 폴더(_internal 포함)를 임의로 지우거나 옮기지 마세요.
- 중요한 장부는 회사 규칙에 따라 별도 백업도 해 두세요.
- AI가 만든 수정은 반드시 「미리보기」로 확인한 뒤 적용하세요.


문의가 필요하면 이 앱을 설치해 드린 담당자에게 연락하세요.
